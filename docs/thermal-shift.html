Thermal shift

Melting temperature from the steepest point of each curve. First column temperature, then one column per well, named like Reference_1, Reference_2, Ligand_1. Instrument exports with one row per well and reading are converted automatically.

What is this for? Finding out how stable a protein is and whether a ligand binds, for example in a buffer or ligand screen. Which assay answers which question →

Needed when the wells are named by position (A01, B01, ...). Assign the samples on the plate below, or paste your plate map from the spreadsheet: row letters down, column numbers across, a sample name per well. Wells with the same name form a group, empty wells are left out.
